# 博客升级与验收计划

本次沿用现有 Spring Boot / Thymeleaf / JPA 架构与已有 Git 历史，每个可验收阶段单独提交。目标是题目要求下可运行、可维护、可以解释的个人技术博客；不承诺没有缺陷。

## 阶段

1. 安全 Markdown：服务端统一解析并清洗 HTML，编辑预览与公开阅读使用同一路径；目录、代码高亮与复制不依赖外部 CDN。
2. 文章成长记录：事务内保存快照，历史只在后台展示；恢复生成新记录且恢复为草稿，防止旧内容意外公开；并发编辑冲突不覆盖新内容。
3. 产品完善：统一视觉、移动端、删除确认、保存反馈、离页提醒、友好错误页；本地文件数据库保留重启后的数据。
4. 交付：回归测试、真实 HTTP 生命周期与重启验证、CI、启动和备份说明、架构与面试演示、AI 使用记录。

## 验收边界

- 保留发布、草稿隔离、搜索、分页、表单校验及既有测试。
- 验证 Markdown 的 XSS / 危险 URL 过滤与超长输入限制。
- 验证创建、修改、恢复、历史归属、删除清理、事务回滚和并发冲突。
- 本地开发默认无需密码；不对公网开放未认证后台。登录与生产 MySQL 不属于本次交付。
- 不伪造提交历史，不自动改写已有提交，不默认推送远程仓库。
- AI 协助实现和测试；演示者需要理解关键设计并如实说明 AI 的使用。

## 本次交付状态

- Markdown、目录、高亮与复制已实现，并通过渲染安全测试和真实浏览器预览验证。
- 修订快照、恢复为草稿、事务与并发保护已实现，并完成真实数据库测试。
- 视觉、移动端、确认删除、反馈、离页提醒、错误页已实现；文件库与 Flyway 已加入。
- 已提供 JVM / 浏览器测试、CI、备份与启动说明、设计和面试材料。
- 验证证据与明确未验收的范围见 `VALIDATION.md`；远程同步以实际 Git 远端校验为准，GitHub Actions 执行结果以远程记录为准。

## 公网准备与界面重做

在用户要求“高级界面、炫技、其他电脑可访问”后，范围新增：

1. 深色编辑风格、完整浅色主题、阅读进度与当前目录定位。
2. 历史和当前正文的逐行差异，增删统计、行号与有限规模算法。
3. shared/public 模式的后台认证、登录限流、非本机监听强制保护。
4. 非 root 容器、持久卷、数据库健康检查、Caddy HTTPS、备份和隔离部署测试。
5. 完整 README、部署/运维文档、CI 扩展、截图更新和阶段 Git 提交。

用户明确选择公网访问，但暂时没有服务器或托管账号，因此本轮交付可部署版本。
真实上线仍需要用户控制的运行平台和 HTTPS 域名，不能把云工作区的 localhost 作为公开网址。

## 评论与星级评分

新增 V2 数据迁移、读者匿名评论及审核后台、浏览器级 1～5 星评分和均分/票数。V1 不变，升级需要先备份再启动新版。功能实现、界面与回归验证、文档按实际阶段提交。没有访客注册；评论审核后公开，匿名评分不保证一人一票。
