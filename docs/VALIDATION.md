## 本次公网版本的诊断与修复

- **默认 BCrypt 字符串没有编码前缀**：真实登录测试发现与 DelegatingPasswordEncoder 不兼容；改为带 `{bcrypt}` 标识，随后通过真实密码和 HTTPS 登录验收。
- **容器内部请求走外网代理**：云环境注入的代理拦截 app 内部地址；对 Caddy 内部上游配置 NO_PROXY，健康检查显式不走外网代理。没有关闭外部 TLS 校验。
- **短文章初始阅读进度过早达到 100%**：改为按文章末端与可滚动范围计算，手机顶部初始进度纳入浏览器检查。
- **公网认证被配置误关的风险**：public/shared 与非本机监听都强制认证，不能仅用布尔开关绕过。
- **差异算法的复杂度**：限定每侧 600 行，避免对任意输入分配无界二维矩阵；超限明确提示，不静默截断。
- **用户从 ZIP 内直接启动**：Windows 脚本增加完整解压提醒，不再只显示无法找到 Maven Wrapper。

## 前期环境与业务诊断

- Maven 缓存目录只读、Java 不自动使用 HTTPS_PROXY → 工作区缓存及仓库外代理配置，未关闭 TLS/依赖校验。
- 只有 Java 运行时而缺编译器 → 补齐经过 Debian 签名索引验证的 Java 21 JDK。
- 云端 IPv6 映射连接重置 → 启动脚本显式使用 IPv4，再做 HTTP 与浏览器验证。
- 多窗口首次编辑竞争基线快照 → 在内存保留原文，乐观写成功后才落库，线程测试验证只有一个赢家。
- Spring Boot 4 的测试切片边界 → 显式引入真实安全配置，不通过关闭过滤器制造通过。
