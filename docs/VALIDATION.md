## 开发中的诊断与修复

- Maven 默认缓存目录只读 → 改为工作区缓存，设置仓库外代理配置，未修改仓库的 Maven 地址或关闭 TLS。
- Java 运行时存在但缺编译器 → 在工作区安装通过 Debian 已签名索引验证的 JDK 包，并使用同版本运行时。
- 云端 Java 的 IPv6 映射连接会重置 → 启动脚本显式启用 IPv4；HTTP 和浏览器已验证。
- Spring Boot 4 的 MVC 切片测试不自动提供完整安全基础设施 → 显式导入安全配置，并使用真实 CSRF 测试辅助器，不关闭过滤器。
- 数据层单元测试隔离与迁移验证职责不同 → Repository 测试使用独立 test profile，迁移测试用真实 Flyway + validate 单独验证。
- 两个窗口第一次修改旧文章可能竞争同一基线 → 先构造内存快照，等文章乐观写入成功后再插入历史；加入真实线程竞争测试。
- 品牌升级后旧页面断言仍期待旧名 → 更新对应展示断言，保留功能断言。

## AI 的使用与验证方式

AI 协助了升级方案、Java/模板/样式实现、测试编写、故障定位和文档整理。所有新增功能都经过实际构建或工作流验证；没有把生成代码直接视为正确结论。

重要证据包括：事务后半段故意失败仍不留下半次修改；两名写入者只有一个成功；CSRF 缺失返回 403；草稿和恢复后的文章公开返回 404；恶意 Markdown 不执行脚本；进程重启后数据仍存在。

项目使用者应结合 `ARCHITECTURE.md` 和 `DEMO.md` 阅读代码、亲自操作并形成自己的理解，面试中如实说明 AI 帮助范围。

## 尚未覆盖的范围

- Windows/macOS 的命令已提供，但本轮实际执行环境是 Linux；未声称在所有操作系统上实测。
- 没有登录认证、多人账号、图片上传、评论、历史压缩和自动备份。
- MySQL、生产访问控制、公网部署、性能压测与完整无障碍审计未验收。
- 代码复制依赖浏览器 Clipboard API；不可用时会提示手动复制。关闭 JavaScript 后仍可提交核心表单，但没有预览、复制和离页提醒。
- 阅读时长按字符数估算，时间统一显示北京时间。历史时间表示快照保存时间，不伪造升级前的编辑时间。
