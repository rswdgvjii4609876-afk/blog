## 确认的问题与修复

编辑页打开后，其他标签页退出登录会导致预览收到 403。旧代码仅提示通用失败，没有指出会话或 CSRF 已失效。此外，fetch 默认跟随重定向，若最终收到 HTTP 200 登录页，旧代码会把它当作预览 HTML。

现在预览识别 401、403 和重定向，不渲染这些响应；明确提醒先复制未保存内容、在新标签页重新登录，避免直接刷新。只有成功的 HTML 响应才进入预览区域。浏览器回归包括真实退出登录和模拟登录重定向，检查正文保留且预览不出现登录表单。修改前真实会话失效回归在等待明确提示时失败。

这不等于自动保存。未保存内容仍只在编辑框里；会话过期后直接提交表单、刷新、关闭页面或浏览器崩溃仍可能丢失输入。长文建议定期保存草稿，遇到登录问题先复制正文。
